# 三方 100% 源码研读工作区

本仓库是 OpenMinis（GPL-3.0）的个人 fork，目标：改造成一个 Muse 式的个人客户端（安卓先行）。

在动任何代码之前，先完成三方独立研读：**每一方都必须 100% 读完本仓库自有源码**（`src/android`、`src/ios`、`scripts`、`docs` 与根目录文件，逐文件逐行；`deps/` 第三方子模块单独建账），各自给出技术阅读、阅读理解、思考与改造方案，互不看稿、独立作答，最后由缪斯逐项对表裁决。

## 目录

| 目录 | 内容 |
|---|---|
| `research/ledger/` | 三方各自的全量文件台账与覆盖率记录（读了多少文件、多少行，以此为准，不许口头声称读完） |
| `research/gemini/` | 谷歌最高档 Gemini（经 Antigravity/agy）的研读报告 |
| `research/dsh/` | DSH（DeepSeek Harness）的研读报告 |
| `research/claude/` | 缪斯的研读报告 |
| `research/synthesis/` | 三方对比、裁决与合并定稿 |

## 纪律

- 分区阅读：每个文件只由一个分区负责读，分区之间不重叠重读；图纸（目录地图、台账）人人可看。
- 结论必须带文件与行号证据；没读到的如实标注，不许冒充。
